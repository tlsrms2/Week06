# 게임 기획안: 블라인드잭 (Blindjack)

## 1. 개요
* **장르:** 싱글 플레이어 퍼즐 전략 카드 게임 (Puzzle-Strategy Card Game)
* **플랫폼:** PC (Windows / Mac)
* **핵심 콘셉트:** 매 스테이지마다 주어지는 '고정된 패'를 활용해 기하급수적으로 폭증하는 할당량을 사칙연산으로 맞추고, 자신의 '시야'를 담보로 생존하는 심리 압박 전략 게임.

---

## 2. 핵심 게임 시스템

### 2.0. 게임 진행
* **라운드 시작:** 플레이어는 일정량의 시야를 배팅.
* **라운드 진행:** 라운드 진행은 블랙젝과 동일. 플레이어는 딜러에게 숫자 카드와 연산 카드 중 하나를 받음. 숫자 카드는 왼쪽에서 오른쪽으로 자동 배치. 연산 카드는 원하는 위치에 배치 후 고정됨.
* **라운드 종료:** 플레이어는 최종 연산 값을 확인하고, 할당량과 비교하여 승패를 결정합니다.

### 2.1. 스테이지 기반 고정 덱 (Fixed Deck per Stage)
* **사전 설계된 시나리오:** 각 스테이지(라운드)마다 덱을 구성하는 숫자 카드와 연산자 카드의 종류, 개수가 완벽하게 고정되어 있습니다.
* **운(RNG)의 배제:** 드로우 운에 의존하는 것이 아니라, "이 고정된 카드들을 어떤 순서로 배치하고 연산자를 어디에 끼워 넣어야 할당량을 맞출 수 있는가?"를 풀어내는 전략적 퍼즐의 성격을 가집니다.
* **엄격한 제약:** '꽝' 카드를 구제하기 위한 재활용이나 카드 조합 시스템은 존재하지 않습니다. 플레이어는 자신에게 주어진 억압적인 환경(고정된 패) 안에서 반드시 생존 루트를 계산해야 합니다.

### 2.2. 기하급수적 할당량 (Exponential Quota)
스테이지가 거듭될수록 요구하는 목표 수치가 비약적으로 증가합니다.
* **승리 조건:** 최종 연산 값이 할당량과 **정확히 일치**하거나, **초과하지 않는 선에서 최대한 근접**해야 합니다.
* **패배 조건:** 할당량을 1이라도 초과(Bust)하거나, 배팅한 시야를 모두 상실한 경우 즉시 게임 오버.
* **스케일링 예시:**
    * Stage 1: 할당량 21 (주어진 패: 1~10 숫자 카드 위주, 덧셈 중심)
    * Stage 5: 할당량 5,000 (주어진 패: 소수의 연산자 [x]와 다수의 작은 숫자들)
    * Stage 10: 할당량 1,000,000,000 (주어진 패: 극단적인 숫자와 [-], [÷]를 활용한 함정 회피 구조)

### 2.3. 사칙연산 카드 배치 로직
* **자동 합산:** 필드에 놓인 숫자 카드들은 기본적으로 '왼쪽에서 오른쪽으로' 자동 더하기(`+`) 처리가 됩니다.
* **연산자 개입:** 플레이어는 손패의 연산자 카드(`-`, `x`, `÷`)를 숫자 카드 사이의 틈에 직접 끼워 넣어 연산의 흐름을 왜곡시킵니다.
* **연산 우선순위 무시:** 수학적 우선순위(곱셈/나눗셈 우선)를 무시하고, 철저히 **배치된 순서(좌->우)**대로만 계산됩니다.
    * *예: [10] [x] [5] [+] [3] = 53*

### 2.4. 시야(Vision) 배팅과 영구 상실 시스템
* **배팅:** 각 스테이지 시작 시, 플레이어는 실패의 리스크를 짊어지고 자신의 '시야(Vision)'를 배팅합니다. 고정된 덱이 주어지므로, 플레이어는 해당 스테이지의 퍼즐을 완벽히 풀 수 있다는 **'자신의 계산 능력'**에 배팅하게 됩니다.
* **상실:** 목표에 도달하지 못하면 배팅한 시야를 영구적으로 잃습니다.
* **시각적/물리적 페널티:** 시야가 줄어들수록 화면 외곽 암전(Vignette), UI 왜곡, 블러 처리가 일어납니다. 수치가 극단적으로 낮아지면 카드의 형태가 뭉개져 마우스를 올려 집중(Focus)해야만 간신히 숫자를 판독할 수 있습니다.
